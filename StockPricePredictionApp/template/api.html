JSON API

All endpoints are served by this Django app under /api/ and return JSON.

Version 1

POST endpoints enforce Django CSRF protection. For browser clients, send the X-CSRFToken header with the value of the csrftoken cookie. Server-to-server scripts can use Django's test client or disable CSRF for the session explicitly.

MethodPathDescription
GET/api/health/Data store status: cached symbol count and freshness.
GET/api/history/?symbol=AAPLOHLCV history with source, staleness and series arrays.
GET/api/quote/?symbol=AAPLLatest quote, day change and freshness metadata.
GET/api/quotes/?symbols=AAPL,MSFTBatch quotes for the local watchlist and alerts.
GET/api/search/?q=appSearch the symbol universe; returns matching symbols and names.
POST/api/refresh/Re-fetch cached data for one or more symbols.

curl snippets

Copy, paste, run

GET Health
curl http://localhost:8000/api/health/
GET History
curl "http://localhost:8000/api/history/?symbol=AAPL"
GET Quote
curl "http://localhost:8000/api/quote/?symbol=AAPL"
GET Search
curl "http://localhost:8000/api/search/?q=app"
POST Refresh
curl -X POST http://localhost:8000/api/refresh/ \
  -H "Content-Type: application/json" \
  -H "X-CSRFToken: $CSRF" \
  -d '{"symbols": ["AAPL", "MSFT"], "force": false}'

Management commands

Run from the project root via manage.py
