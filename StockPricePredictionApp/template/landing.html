AI FORECAST, EXPLAINED

A second opinion that shows its report card.

Not a crystal ball. StockSight trains on one stock's own history, tests itself on unseen data, and tells you when to ignore it.

What it does

It learns patterns from daily closing prices, then projects the next 1–90 trading days. The BUY / SELL / HOLD signal summarises the projected direction; the metrics tell you how much weight it deserves.

01
Pull the history

Up to 10 years of daily OHLCV, refreshed from the local cache.

02
Train locally

LSTM first, then Gradient Boosting or NumPy if TensorFlow isn't available.

03
Validate honestly

A chronological 90/10 split keeps the test set unseen — no look-ahead leakage.

04
Project & explain

Day-by-day prices, a range, a signal and accuracy metrics in plain language.

QUESTIONS

The short answers.

Do I need an account?

No. There is no signup, sign-in, email capture or paywall. Open the dashboard and search a ticker.

Is the data live?

Prices are daily end-of-day bars, refreshed after the next expected US market close. It is not an intraday streaming feed. News refreshes on a separate six-hour cycle.

How accurate is AI Forecast?

Each result shows direction accuracy on a chronological holdout, RMSE, MAPE and a naive-baseline comparison. If direction accuracy is near 50%, the model is no better than a coin flip — ignore it. It is a statistical estimate, not investment advice.

What happens if the data provider is down?

The cached file is served and clearly marked STALE. StockSight retries after a short cooldown; it never fabricates a price or headline.

Can I use the API?

Yes. History, quote, prediction, search and health endpoints are available without a key. See the API Docs page inside the dashboard.
