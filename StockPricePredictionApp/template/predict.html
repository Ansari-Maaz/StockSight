What is AI Forecast?

StockSight trains a model on the selected stock's historical daily prices and projects the next 1–90 trading days. The BUY / SELL / HOLD signal compares the projected path with the model's validated direction accuracy. It is a statistical estimate — not investment advice or a guarantee.

Enter a symbol above and press Run forecast. Training happens on this machine from the latest cached prices; subsequent runs reuse the model until new market data arrives.

01 LSTM TensorFlow neural network for sequence learning (preferred).
02 Gradient Boosting scikit-learn trees — fast fallback when TensorFlow is unavailable.
03 NumPy Lightweight regression fallback that always runs locally.
