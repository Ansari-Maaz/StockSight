What is AI Forecast — and why use it?

It trains a model on the selected stock's own historical daily prices and projects the next 1–90 trading days. The BUY / SELL / HOLD signal summarises the projected direction, while the accuracy metrics tell you how much weight to give it. It is a statistical second opinion — not investment advice or a guarantee.

01 Sanity-check a hunch See whether years of price history actually support the direction you believe in.
02 Plan scenarios Use the projected range to stage entries, set alerts, or decide when to wait.
03 Know when to ignore it If holdout direction accuracy is near 50%, the model is no better than a coin flip.

Enter a symbol above and press Run forecast. Training happens on this machine from the latest cached prices; subsequent runs reuse the model until new market data arrives.

01 LSTM TensorFlow neural network for sequence learning (preferred).
02 Gradient Boosting scikit-learn trees — fast fallback when TensorFlow is unavailable.
03 NumPy Lightweight regression fallback that always runs locally.
